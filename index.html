Proof through projects

Do more than finish lessons

A credible learning record includes the decisions, mistakes, tests and improvements behind the final result—not only the final screenshot.

  • Readable codeStructure and naming that another developer can follow.
  • VerificationTests, checks and expected results that demonstrate behavior.
  • DocumentationA clear README explaining the problem, setup and trade-offs.
  • DeploymentA working result shared in an appropriate environment.
